# sakki — さっきの自分

手続きで迷ったあなたを、完了画面で「さっきの自分」が待っている Chrome 拡張。

- 何画面か続く手続きを終え、途中で迷っていた時だけ、名札「さっきの私」を付けた半透明の自分が完了画面に現れる
- 押すと、さっきの自分が、その時のページの見た目（色・並び・画像・本文）の上を早送りで走り直す。一番時間を損した 1 か所でだけ普通の速さに戻り、そこに赤い渦が 1 つ残る
- 入れた値・選んだ物・名前・数字・メールの形は記録する時点で伏せ字になる（写すページの上でも同じ規則 1 本）
- 記録は端末のメモリの中だけに残る（ディスクにも外にも出さない）。サーバー・アカウント・LLM は使わない

状態: MVP を作っている途中。今できるのは「同意 → 記録 → 完了画面の角で待つゴースト／拡張のアイコンで side panel を開くと、実際のページの見た目の上でさっきの自分が早送りで走り、一番の迷いに赤い渦」まで（動画はこれから）。

## 試す（build は要らない）

1. `chrome://extensions` を開き、右上の「デベロッパー モード」を入れて「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
2. 偽の手続き（30 秒）が自動で開く。同意の欄に印を付けて最後まで進める
3. ツールバーのパズルの形のボタンから sakki を押すと、右の欄で「さっきの私」が走り直す。ほかのサイトの手続きの後でも同じ

記録するのは、focus・click・入力の回数と順、ホスト名と時間、見出しが替わった瞬間のページの写し（DOM を HTML にした物）。写しには伏せる規則を当ててから取る: 入れた値は ●●●、選べる物の文字は全部 ■、覚えた値・数字・メールの形は ■。script・隠した欄・よそのサイトの枠の中身は写さない（枠・canvas・動画は灰色の箱）。社内のページ（ドットの無いホスト・社内 IP・.local）は写さず、骨組みの絵だけ。

## 検査

```sh
npm test                    # 伏せる規則・記録の単位・再生（node だけ・依存なし）
npm install && npm run e2e  # 実機: Chrome for Testing に拡張を読ませて題材のページを操作する（npx playwright-core install chromium が要る）
```
