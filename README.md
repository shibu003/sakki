# sakki — さっきの自分

手続きで迷ったあなたを、完了画面で「さっきの自分」が待っている Chrome 拡張。

- 何画面か続く手続きを終え、途中で迷っていた時だけ、名札「さっきの私」を付けた半透明の自分が完了画面に現れる
- 押すと、さっきの自分が早送りで走り直す。一番時間を損した 1 か所でだけ普通の速さに戻り、そこに赤い渦が 1 つ残る
- 名前や金額は記録する時点で伏せ字になり、画像は空の箱になる。だから、その 10 秒をそのまま動画で人に渡せる
- 記録は端末の中だけに残る。サーバー・アカウント・LLM は使わない

状態: MVP を作っている途中（まだ入れて使える形ではない）。
